Invariants Maximum oracle Predictive

Delta is the escaping fixture. Its title, one reference title, one reference URL and one reference description all contain characters that must be entity-encoded on the way into HTML: <, >, &, and a literal </script> sequence that would otherwise close the surrounding element on any page that emits the title inside a script block.

The title reaches the page title, the visible heading, the meta and og:description machinery, the JSON-LD blocks, the search index, the RSS feed and the llms.txt digests. Every one of those is a separate encoder, which is exactly why one fixture entry is pointed at all of them.
